# UI 首屏核验记录

日期：2026-08-22

## 首页预览结果

本地 Workbench 预览在桌面视口中显示：任务模板区域已从主卡片底部移除，聊天输入框、附件入口、权限选择与提交按钮同屏可见；主卡片和右侧上下文栏的上方留白已缩减。

## 待处理现象

点击首页“Connect third-party API”后，浏览器预览出现空白画面，尚未确认独立 API 配置窗口实际渲染。下一步应通过浏览器控制台查看 React 运行时错误并修复后复测窗口中的可编辑 Base URL。

## 修复后复测

重新加载预览后，首页“Connect third-party API”能够打开独立的深色 Inspector 窗口。窗口中已可见供应商下拉框、可编辑“连接地址 / Base URL”、模型名称、显示名称、API key 和“连接并测试”按钮；DeepSeek 默认地址显示为 `https://api.deepseek.com/v1`。窗口采用背景模糊、顶部标题栏和右上关闭按钮。

首页仍在同一桌面视口内显示聊天输入框、附件入口、权限选择与提交按钮，任务模板区域未再渲染。

切换到“MiMo Token Plan（中国）”后，地址输入框显示并允许编辑 `https://token-plan-cn.xiaomimimo.com/v1`，模型字段预填 `mimo-v2.5-pro`，同时显示 `sk-`/`tp-` 选择提示。

## 用户澄清后的窗口复测

已移除独立深色 API 配置浮层。首页模型连接入口现在打开原有的 API 设置窗口；该窗口内保留原有三步布局和服务预置。地址字段已整合到原表单中，位于 API key 正上方，DeepSeek 预填地址可直接编辑。此前关于黑色独立配置窗口的复测结论已不再作为当前界面验收依据。
