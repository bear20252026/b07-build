# 单内容 Inspector 迁移契约

**状态：** 已实施
**日期：** 2026-08-22

## 目标

所有复杂、低频或高信息密度页面均以独立的 **单内容 Inspector** 呈现。该窗口覆盖在保持可辨认的首页背景之上；首页侧栏、任务画布和浮动角色不得被替换为第二套设置应用。

## 统一窗口结构

每个 Inspector 只允许以下结构：

1. 顶部小型来源标签、页面标题、简短边界说明和右上关闭按钮。
2. 单一可滚动内容区，由页面自身管理卡片、表单、预览与审计信息。
3. 低强度背景模糊、居中圆角面板、固定的内容边界。
4. Esc、右上关闭按钮和无未提交敏感输入时的遮罩点击关闭。

禁止在 Inspector 内重新渲染左侧设置导航、返回聊天按钮、二级工作区侧栏或以替换首页为目的的宽幅页面。

## 页面注册表

| 页面 | 打开来源 | 模板 |
| --- | --- | --- |
| API 连接 | 首页 `⌁` 与左下设置入口 | 单内容 Inspector |
| 工作区与文件 | 首页 `▤` | 单内容 Inspector |
| 终端与编码 | 首页 `›_` | 单内容 Inspector |
| 项目产物 | 首页 `▧` | 单内容 Inspector |
| Companion | 首页 `◉` 与浮动角色入口 | 单内容 Inspector |
| 已连接模型、运行记录、扩展与能力、安全系统 | 页面动作、命令面板或受控跳转 | 单内容 Inspector |
| Companion Studio 各三级页面 | Companion 页面内的明确动作 | 单内容 Inspector |

## 实现约束

1. `Sider` 始终渲染主工作区导航；它不再有 settings-mode 或浮层内部设置导航分支。
2. `SettingsOverlay` 与 `WorkbenchOverlay` 都是单内容外壳；前者服务现有页面意图，后者服务首页标题栏的快捷入口。二者不得引入内部导航。
3. 页面只发出前端导航/Inspector 意图；不得因打开窗口而连接 Provider、读取目录、执行终端或启动后台能力。
4. 所有视觉新增必须在 CSS 性能预算内完成；优先删除旧壳样式而非堆叠新规则。
