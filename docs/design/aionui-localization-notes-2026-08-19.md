# AionUi 参考界面本地化设计笔记

本笔记只提炼用户提供截图中可观察的**视觉语言**，不复制其品牌资产、图标或原始页面结构。

| 观察维度 | 参考界面可验证特征 | AI Work OS 本地化映射 |
|---|---|---|
| 浅色基础 | 大面积暖中性近白背景、浅灰侧栏、极细边界、黑灰文本 | 将工作台默认主题调整为浅色石墨体系，使用暖灰画布和半透明白卡片 |
| 深色基础 | 近黑画布、略浅的石墨侧栏、低对比卡片与边界，白色高层文本 | 保留深色模式，但以石墨和烟灰替代高饱和深蓝底色 |
| 强调色 | 主控件几乎不使用高饱和色；选中项为灰色浅层，状态色克制 | 仅保留低饱和靛蓝作为焦点环和主要提交按钮；审批、错误、成功采用柔和语义色 |
| 圆角与阴影 | 输入框与选择组圆角较大；设置卡圆角约 10–16px；阴影极轻 | 任务编辑器采用 18px 圆角，运行时与引用卡采用 12px 圆角与柔和投影 |
| 信息密度 | 左侧持久导航轻量、正文居中留白明显、输入区位于主要视觉焦点 | 侧栏继续承载工作区导航；中心保留任务目标与真实事件；右栏放置交付与知识引用 |
| 字体层级 | 标题字重明显但不夸张；辅助文字灰度较低；控件文字紧凑 | 使用系统 UI/CJK 字体栈，降低元信息对比度，强化任务状态与审批动作 |

> 当前截图显示的是浅色聊天首页和深色设置页。此次实现采用可切换的浅色优先石墨风格，而不是复刻截图中未与 AI Work OS 业务对应的账户、模型或设置页面。


## 浏览器验收（工作台）

| 主题 | 已验证结果 |
|---|---|
| 浅色优先 | 暖灰背景、浅灰持久侧栏、白色任务卡与引用预览卡、低对比边框、深石墨文本均可见；中心目标输入框保持主要焦点。 |
| 石墨深色 | 近黑画布、石墨侧栏与低对比面板层级可见；文字、审批状态和主要提交按钮仍具有清晰对比。 |
| 业务保持 | Build / Plan / Explore 切换、任务目标输入、真实快照区域、任务事件流、右侧交付与引用标签均继续存在。 |

> 验收中未启动或伪造任务执行；此次仅验证视觉主题与已有交互入口的呈现。


## 真实业务回归

在石墨深色主题下提交 Build 目标“验证本地化界面下的可恢复任务闭环”后，工作台显示：并发峰值 1、等待审批快照、3 个节点、9 条真实事件，以及“批准并恢复 deliver”和“从快照恢复”入口。此结果确认本次 UI 本地化没有替换或伪造任务运行时状态。
