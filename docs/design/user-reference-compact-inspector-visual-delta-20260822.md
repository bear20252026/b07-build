# 用户参考图：紧凑三级 Inspector 视觉差异

**日期：** 2026-08-22

## 参考优先级

本轮的视觉唯一基线是用户上传的三张参考图，尤其是其中的 Companion 与 API 连接 Inspector。它们表达的是紧凑、聚焦、悬浮的三级工作面；不以当前宽幅设置页为基线。

## 现状与目标

| 维度 | 当前实现（用户不接受） | 参考图目标 |
| --- | --- | --- |
| 面板占比 | 设置面板接近整个窗口宽高，像替换主工作区 | 居中、约占视口 68–78% 宽度与 58–76% 高度的独立卡片 |
| 背景 | 主内容被大面板覆盖，模糊与层次不明显 | 首页仍可辨认；低强度灰白模糊、降低饱和，不参与交互 |
| 侧栏 | 外层应用导航和设置浮层导航在视觉上争夺层级 | 三级浮层内部独立窄侧栏，主应用侧栏只作为背景存在 |
| 标题栏 | 标题和内容区纵向占用偏大 | 顶部紧凑标题栏：上方小型面包屑、标题、简短说明、右上关闭 |
| 内容密度 | 工作区文件页按全宽卡片堆叠 | 内容在右侧受限宽度中形成两栏或信息块；复杂长表单自身滚动 |
| 视觉边界 | 白色大面板缺少悬浮感 | 20–24px 圆角、1px 低对比边框、柔和向下投影，背景与面板有明确层次 |
| API / Companion | 使用了不同的 `WorkbenchOverlay`，虽为浮层但与设置页不一致 | 所有三级详情使用同一紧凑 Inspector 外壳，视觉一致 |

> 原先实现的文件、目录、格式预览与终端命令计划均保留；只重做其信息容器、信息密度和屏幕层级，不退回为首页卡片。

## 具体 CSS 与交互约束

1. 设置遮罩应固定全屏并使用 `blur(6px–8px)`；主页面不被隐藏或重新布局。
2. Inspector 面板应以 `width: min(980px, calc(100vw - 32px))` 为默认桌面上限，而非 1240px；高度上限为 `min(720px, calc(100dvh - 64px))`。
3. 内部导航宽度为 170–184px；内容区使用 16–20px 内边距；内容超出时只滚动右侧内容区。
4. 文件页在桌面用 `minmax(0, 1.2fr) minmax(250px, .8fr)` 的局部网格；窄屏退化为单列。
5. 终端页与 Provider 页的控制项保持纵向紧凑，不增加首页高度，不使用粗重大标题。
6. 页面关闭可由关闭按钮、Esc 或遮罩点击触发；遮罩点击不得关闭存在未提交敏感输入的表单。

## 不变的安全边界

视觉重构不会改变 Provider 的内存密钥策略、受控文件导入、原生目录路径不回显、固定终端命令计划、逐步审批或 Companion 权限边界。
