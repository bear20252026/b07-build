# 工作区文件、终端与三级 Inspector 契约

**状态：** 实施中
**日期：** 2026-08-22

## 1. 全局呈现规则

复杂设置必须通过独立的 **三级 Inspector 浮层** 打开。首页、左侧导航和对话上下文仍保留在其后方；背景使用低强度模糊与半透明遮罩，浮层以居中的圆角面板呈现。设置页不再占用主工作区区域，也不得把工作区聊天滚动容器挪到设置内容之下。

| 层级 | 作用 | 进入方式 | 退出方式 |
| --- | --- | --- | --- |
| 首页 | 任务发起、项目入口、对话与应用内 Companion | 应用启动 | 不适用 |
| 二级设置分类 | 模型、工作区、运行记录、扩展、安全 | 左下角设置 | 返回首页 |
| 三级 Inspector | 具体 Provider、工作区文件、终端与编码、角色系统页面 | 分类页面明确入口 | 关闭按钮、Esc、点击遮罩 |

## 2. 工作区默认目录

工作区目录是用户明确选择的**根目录引用**，仅用于用户发起的导入、生成产物导出和终端任务工作目录。不能把绝对路径写入任务事件、Provider Profile、聊天内容、传输 DTO 或 Git 提交。桌面端可在应用私有配置中保存经用户选择的本地引用；网页与移动端不保存或显示系统绝对路径。

目录选择后只显示脱敏标签，例如“已选择本地工作区”，而非驱动器、用户名或完整目录。尚未经用户确认的文件不会扫描、同步、上传或注入 Agent 上下文。

## 3. 文件与文件夹导入

| 入口 | 允许能力 | 禁止能力 |
| --- | --- | --- |
| 导入文件 | 用户显式选择一个或多个静态文件；读取名称、扩展名、大小和受限预览 | 自动执行、自动上传、自动加入任务、宏运行 |
| 导入文件夹 | 用户明确选择后展示有限清单 | 整盘扫描、递归无限扫描、隐式同步、符号链接穿透 |
| 压缩包 | 作为归档对象登记并显示类型、大小与哈希摘要 | 自动解压、运行归档内脚本、从归档触发命令 |
| 文档与二进制 | 静态归档并按类别选择预览器 | 执行嵌入对象、加载 Office 宏、调用外部查看器 |

前端接受常见文本、代码、结构化数据、文档、表格、演示、压缩、媒体和二进制格式的分类登记；“可安全预览”是更窄的集合。文本预览必须限大小、限字符数并按检测到的编码显示；未知或大文件只显示元数据。

## 4. 终端与编码

终端页面只构造**命令计划**，包含工作区引用、受限命令模板、用户提供参数、影响等级与审批状态。它不直接执行任意字符串，不接受上传文件、网页、模型输出或聊天内容作为可执行命令。

初始模板仅覆盖可解释的编码任务：`npm test`、`npm run build`、`cargo check`、`python -m compileall` 和用户工作区内的受控脚本目标。每次执行必须明确显示命令、工作目录、预期副作用与输出上限，并由“逐步审批”流程确认；自动化模式不能绕过这一确认。所有输出作为长度受限的本地任务投影，绝不回显环境变量、凭据或完整绝对路径。

> 上传文件、选择目录、配置模型或打开角色窗口均不授予终端权限。终端计划和真实进程生命周期必须经过独立的审批与审计边界。

## 5. 平台差异

| 平台 | 目录 | 文件 | 终端 |
| --- | --- | --- | --- |
| Windows 桌面壳 | 原生目录选择，最小 scope | 原生多文件选择与受控复制 | 可创建审批式命令计划；实际运行需桌面壳受限执行器 |
| 浏览器 | 不显示绝对目录；使用会话导入 | 浏览器多文件输入 | 不提供系统终端 |
| Android / iPadOS | 不支持文件夹选择；保留应用内工作区语义 | 系统文件选择器 | 不提供系统终端 |

## 6. 版权与设计归属

本契约延续 AFFiNE 的“内容在画布、低频控制在独立表面”理念与 Apple-first 视觉 token，但本轮不会复制 AFFiNE 的 MPL-2.0 源码。上游页面结构与许可证判断见 `docs/research/affine-apple-first-surface-assessment-20260822.md`；Tauri 文件/终端权限证据见 `docs/research/tauri-workspace-file-terminal-boundaries-20260822.md`。
