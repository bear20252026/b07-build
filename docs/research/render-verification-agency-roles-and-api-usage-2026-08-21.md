## 边界观察

Vite 使用非默认的 4173 端口时，被 Gateway 的已审核开发源 CORS 规则拒绝；改用默认的 5173 后，应用可成功附着并读取真实本机数据。这是受控 CORS 行为，而不是产品渲染缺陷。

本次没有发起任何第三方 Provider 推理，因此 API 使用页面正确显示空账本；不应人为注入或伪造调用量来制造非真实 UI 数据。现有 Gateway HTTP 回归已验证真实完成推理后写入脱敏收据的逻辑。
