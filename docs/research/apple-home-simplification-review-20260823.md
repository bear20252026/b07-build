# AI Work OS 首页：Apple 式简化设计复核

## 参考与边界

本轮依据用户提供的多张桌面应用截图、Apple Human Interface Guidelines、getdesign.md 的 Apple 设计分析，以及 Unsloth 公开界面节奏进行复核。只研究信息层级、配色、表面、圆角、留白和输入区布局；不复制任何第三方源码、品牌资源或功能。

* Apple HIG 的核心取向是：让最重要的内容获得足够空间、将非关键细节放到其他视图或按需呈现、清晰区分控件与内容、以渐进披露减少首屏拥挤。
* getdesign.md 对 Apple 的公开视觉分析强调 SF Pro、充足留白与克制的高端单色体验；这符合 AI Work OS 已采用的系统字体策略。
* 用户提供的参考图共同呈现了冷白 / 石墨黑主画布、低饱和中性灰分层、单一蓝色主操作、柔和阴影和更大圆角。其首页均先提供明确的输入意图，再在输入后扩大聊天内容，而不是把模型设置、执行模式、建议卡和运行信息堆叠在首屏。

## 当前偏差

当前首页的薄荷绿外层背景、绿色描边与绿色提交按钮，容易将应用误读为单独品牌皮肤，且与既有 Apple 灰白 / 深灰体系不一致。模型连接、工作模式、建议、Profile 与角色组件同时可见，挤压了输入框与后续聊天区。虽然信息完备，但首屏的视觉焦点分散。

## 待确认的实现方案

1. 删除首页薄荷绿背景、绿色边框、绿色提交按钮和所有首页绿色强调，恢复 light: `#F5F5F7 / #FFFFFF / #E5E5EA / #007AFF`，dark: `#000000 / #1C1C1E / #2C2C2E / #0A84FF` 的中性 Apple 体系。
2. 主窗口采用统一圆角与极轻阴影，不再以彩色外框制造层级；按钮仅使用系统蓝作为单一主操作色，其他按钮转为透明或中性灰。
3. 首页仅保留窄侧栏、模型状态标题、欢迎语和主输入框。模型连接、Profile、工作方式、建议、文件、终端、产物等现有功能不删除，但移到设置入口、弹层或在用户开始对话后按需出现。
4. 输入前：欢迎语和输入框位于主画布中段；输入后：欢迎语淡出，消息时间线从标题栏下方延伸至输入框上方，形成占据大半窗口的连续聊天区。
5. 继续维持当前直接 Provider、模型选择、会话恢复和 SSE 流式事件绑定，所有修改限于布局、CSS token 与现有 UI 的呈现条件。

## 实施核验记录

已在本地 Workbench 首屏核验：首页外层恢复为中性浅灰，窗口、侧栏和主画布不再使用薄荷绿背景、绿色边框或绿色主按钮；系统蓝承担主操作强调。未连接状态继续显示现有模型连接与任务入口。已添加“会话有内容时收起欢迎与上下文卡、展示消息时间线”的呈现条件，下一步需用本地会话样本核验该状态的全屏对话密度。

本地临时会话样本已验证：欢迎区、模式卡和连接卡在已有消息时会消失，用户与模型消息在输入框上方形成连续对话时间线。视觉复核还发现应用内 Companion 悬浮层会覆盖输入区右侧，因此它应在首页对话画布隐藏；用户仍可通过既有标题栏入口打开独立 Companion 窗口。

最终首页核验显示：主窗口恢复白灰分层、系统蓝用户气泡与提交操作；标题栏只保留命令面板与 API 管理入口；工具栏中的文件、终端、产物和 Companion 按需入口不再占据首页。临时会话样本已在核验后从浏览器本地存储清除。
