# Tauri 工作区文件与终端边界核验

**日期：** 2026-08-22
**用途：** 为 AI Work OS 的工作区目录、用户导入、格式预览与终端编码设置定义桌面端最小权限边界。

## 官方能力结论

Tauri Dialog 插件在 Windows、Linux 与 macOS 支持原生文件或目录选择；Android 与 iOS 不支持文件夹选择，因此移动端只能采用文件上传或应用内目录语义。[1] 选择文件/目录的结果可被加入文件系统与 asset protocol 的访问范围，但不应把该机制解释为永久、无限制的文件系统授权。[1]

Tauri 文件系统插件将危险操作与路径 scope 分开处理：启用读取或写入命令本身不足以访问路径，实际调用仍需要显式 allow scope；路径穿越被拒绝。[2] 因此本项目不能授予 `$HOME/**/*`、整盘符或递归任意目录 scope。工作区根目录只能由用户通过原生目录选择器显式选定，并由原生层以受控根目录对象保存；导入文件会复制到该根目录下的受控 `imports/` 子目录。

Tauri Shell 插件将子进程执行定义为高风险能力，执行权限应通过已配置的命令与参数 scope 授予。[3] 本项目不启用通配 Shell、`cmd /c`、PowerShell 任意参数或前端传入的可执行路径；终端页面仅创建待审批的命令计划，真实运行应由现有受控执行管道在逐步审核之后接手。

## 本项目实施约束

| 能力 | 桌面 Windows | Web / Android / iPadOS | 安全约束 |
| --- | --- | --- | --- |
| 选择默认工作区目录 | 原生目录选择器 | 不可提供系统绝对路径；以浏览器文件导入替代 | 目录由用户明确选择；不递归扫描或上传。 |
| 文件导入 | 原生文件选择器及浏览器文件输入 | 浏览器文件输入 | 只接收静态文件；不执行、不自动解压、不运行宏。 |
| 文件夹导入 | 原生目录选择器；后续可选择显式导入清单 | 浏览器可选文件夹输入（浏览器支持时） | 显示清单；需用户确认才复制到 `imports/`。 |
| 格式识别与预览 | 受控本地投影 | 受控本地投影 | 文本类仅限长度预览；PDF/DOCX/压缩包显示元数据或隔离后清单。 |
| 终端编码 | 仅 Windows 桌面壳的审批式命令计划 | 不支持系统终端 | 禁止任意命令、环境继承、自动执行与来自上传内容的命令。 |

> 不能以“支持 90% 文件格式”为理由自动解析、执行、解压或上传未知二进制。系统将把“接受/归档”和“可安全预览”拆开：可导入常见文件类型，安全预览只覆盖静态文本、结构化文本和经过专用解析器审查的格式。

## 初始格式策略

| 类别 | 示例扩展名 | 初始处理 |
| --- | --- | --- |
| 纯文本与代码 | `txt`, `md`, `json`, `yaml`, `toml`, `xml`, `csv`, `ts`, `tsx`, `js`, `py`, `rs`, `java`, `go`, `c`, `cpp`, `cs`, `sh`, `ps1`, `sql`, `html`, `css`, `tex` | 限长只读文本预览；保留字符编码检测结果。 |
| 办公与文档 | `pdf`, `doc`, `docx`, `odt`, `rtf`, `epub` | 导入并显示元数据；`pdf`/`docx` 待专用受控提取器接入后才生成正文预览。 |
| 表格与演示 | `xls`, `xlsx`, `ods`, `ppt`, `pptx` | 导入并显示元数据；不执行宏、不运行嵌入对象。 |
| 压缩包 | `zip`, `7z`, `tar`, `gz`, `bz2`, `xz`, `rar` | 导入并显示归档标记；默认不自动解压。 |
| 图像、音频、视频 | 常见图像、音频、视频后缀 | 导入并显示媒体类型；不由文件名触发外部程序。 |
| 可执行或脚本载荷 | `exe`, `msi`, `dll`, `bat`, `cmd`, `ps1`, `sh`, `jar`, `py`, `js` | 可作为静态代码/二进制导入对象；默认绝不执行。 |
