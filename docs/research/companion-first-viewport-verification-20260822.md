# Companion 首屏与 3D 呈现复核（2026-08-22）

## 实测范围

在云端 Chromium 的 877×748 视口中，打开工作区首页、设置浮层的“扩展与能力”二级页、以及 Companion Agent 三级页进行人工验证。

| 项目 | 复核结果 | 结论 |
| --- | --- | --- |
| 工作区首页 | 浏览器报告 `Pixels below viewport: 0` | 首页本身在当前视口无纵向滚动，仍只保留任务发起与按需设置入口。 |
| Companion 摘要 | 显示“当前可见：2D 动态玩偶（VRM 待导入）” | 不再把没有资产的状态称作已显示 3D 人物。 |
| Companion 三级页 | 浏览器报告 `Pixels below viewport: 0`；视觉、渲染、语音与四项高影响能力均在同一屏 | 默认控制面已压缩至首屏，且核心开关与状态无需滚动即可审查。 |
| 3D 选择 | 显示“VRM 模型尚未导入”“VRM 舞台（待导入模型）” | 当前无真实 VRM 模型。选择 3D 仅登记舞台请求，视觉呈现回退到已有 2D 动态玩偶。 |

> 结论：此前的“3D / VRM 舞台”是渲染意图而不是已加载的 3D 资产，造成了错误期待。本轮已把状态、说明与回退行为一致化。真实 VRM 人物仍需要后续通过本地、经来源/版权/大小/安全审查的模型导入流程实现，不能用空舞台或网络自动下载代替。

## 三级悬浮工作面复核（第二轮）

在同一云端 Chromium `877×748` 视口中，首页右上出现三个紧凑的独立入口：API 连接（`⌁`）、项目产物（`▧`）与 Companion（`◉`）。首页仍报告 `Pixels below viewport: 0`；对话编辑器新增“收起”按钮，收起后保留草稿并提供“展开对话编辑器”动作。

点击 Companion 后，工作区背景以模糊处理保留，前景显示独立圆角浮层。浮层中已可见 Orbit 角色、角色呈现状态、MiMo TTS 状态、“配置语音 API”和“角色控制”两个独立动作。状态明确为“VRM 待导入 · 2D 回退可见”，因此此次可见角色是动态 2D 呈现，不将其描述为已导入的真实 VRM 3D 模型。

截图路径（会话临时证据）：`/home/ubuntu/screenshots/127_0_0_1_2026-08-21_19-05-20_3657.webp`。

## 本地程序化 3D 呈现复核（第三轮）

最新云端 Chromium 截图中，点击标题栏 `◉` 后显示的不是空 VRM 舞台，也不是原有 2D PNG 玩偶，而是本地 CSS 透视/变换构成的立体机器人角色，包含头部、发光双眼、躯干、双臂和双腿，并有待机上下浮动与眨眼动画。它不下载网络资产，不读取文件，也不访问麦克风或桌面。

其真实状态应表述为“**本地程序化 CSS 3D Companion；VRM 待导入**”。它不是 VRM 模型，也不使用 WebGL。后续只有当一个来源、许可证、大小与安全扫描均明确的本地 VRM 资产完成导入并成功初始化后，才能把状态改成“VRM 已加载”。

截图路径（会话临时证据）：`/home/ubuntu/screenshots/127_0_0_1_2026-08-21_19-10-57_8538.webp`。

## API 与项目产物独立浮层复核（第四轮）

通过 Companion 窗口的“配置语音 API”操作可切换到独立的 API 连接浮层。该浮层保留 Provider 选择、API key 输入和显式保存，但底层对话并未替换；背景保持模糊，连接表单不再作为首页内容。

通过标题栏 `▧` 可打开“项目产物”独立检查器。检查器提供 Files、Code、Diff、Delivery 与 Citations 五个只读/受控标签，设计上可呈现 Markdown、代码和 JSON 文件投影。本次浏览器中尚未执行产生 `filesystem.write` 事件的任务，因此它诚实显示“0 / No viewable file has been generated”，未插入虚假示例文件，也未读取任意本机目录。

截图路径（会话临时证据）：`/home/ubuntu/screenshots/127_0_0_1_2026-08-21_19-11-26_6170.webp`（API）与 `/home/ubuntu/screenshots/127_0_0_1_2026-08-21_19-12-13_2622.webp`（产物检查器）。

## 首页正式浮动 Companion 复核（第五轮）

在云端 Chromium `877×748` 首页，程序化 3D Orbit 已作为独立浮动角色直接显示在右下区域，不需要打开原有 `◉` 设置/检查器浮层。它提供“静止、漫步、环绕、设置”控制；初始状态为“ORBIT · 漫步”，点击“静止”后可见标签即时变为“ORBIT · 静止”。现有设置页入口仍保留，配置内容没有回填或堆入首页。

角色主按钮声明并采用 Pointer Events，以同时支持鼠标、触控和触控笔；浏览器验证覆盖了默认显示和路线切换。由于当前云端浏览器不连接实际移动设备，触控手势需在 Android/iPadOS 真机继续验收。截图路径：`/home/ubuntu/screenshots/127_0_0_1_2026-08-21_19-32-37_3873.webp`。
