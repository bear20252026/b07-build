# AI Work OS 0.1.13 聊天稳定性与圆润 UI 回归清单

本清单验证 0.1.13 的流式聊天稳定性与高频圆润 UI 重构。普通聊天继续经 Tauri 原生 HTTPS/SSE 直连已选第三方 Provider，不能回退到 Gateway。

| 场景 | 操作 | 通过条件 |
|---|---|---|
| 首屏输入 | 在首页输入、删除、重新输入草稿，但不发送。 | 首页信息以轻量透明度/位移动效响应，不使用高度、边距或伪内容重排；Composer 位置稳定，没有跳闪或大幅页面收缩。 |
| 流式长回答 | 选择任意已连接 Provider，发送要求较长回答的问题并停留在底部。 | 文本持续增长时仅当前助手消息刷新；历史消息、标题栏、侧栏与 Composer 不抖动；滚动保持底部且不会产生无效重复滚动。 |
| 阅读历史 | 在流式回答期间向上滚动，再点击“跳到最新”。 | 向上阅读时不会被强制拉回；跳到最新后仅在内容高度真实变化时跟随最新消息。 |
| 稳定历史 | 发送包含普通文本、公式、搜索运行卡和图片附件的多轮会话。 | 已完成消息的复制、分支、公式和运行卡保持可用；流式刷新不重复解析或视觉重绘稳定历史。 |
| 圆润界面 | 检查首页连接卡、配置按钮、消息、搜索运行卡、时间线工具与 Composer。 | 组件使用统一的柔和曲率和胶囊式操作控件；没有突兀方块；焦点、悬停和按压反馈简短且克制。 |
| 深色与减少动态 | 切换深色主题并启用 Windows “减少动态效果”。 | 黑灰蓝层级、文字对比和圆角保持一致；非必要消息/Inspector/环境光动画关闭，聊天和滚动仍可用。 |
| 窄窗口 | 缩窄窗口并打开上下文预算、检查点、用量账本和知识库。 | Composer、发送按钮和关闭入口可见；Inspector 内部单独滚动，背景不可交互，无内部侧栏或内容溢出。 |
| Provider 边界 | 在龙猫、DeepSeek、MiMo 和一个自定义连接中各发送一轮。 | 每次使用用户当前显式选择的 Provider/模型；清单仍声明 `canAutoStartGateway=false`、`bundlesExplicitGatewaySidecar=false`。 |
