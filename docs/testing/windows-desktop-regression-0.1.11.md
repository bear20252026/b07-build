# AI Work OS 0.1.11 Windows 性能与动效回归清单

本清单验证 0.1.11 的本地性能健康摘要、长会话渲染优化与减少动态支持。普通聊天仍应保持 Tauri 原生 HTTPS/SSE 直连第三方 Provider；安装器不应包含或自动启动显式 Gateway sidecar。

| 场景 | 操作 | 通过条件 |
|---|---|---|
| 性能健康摘要 | 在有聊天和流式文本的会话中打开“性能观察”。 | 仅显示本机数值样本、健康状态、可见窗口与持久化/调度/时间线耗时；不显示正文、密钥、模型、地址、代理、文件名或路径。 |
| 流式持久化 | 对可流式输出的已配置 Provider 发送较长问题，并在完成后关闭/重新打开应用。 | 输出连续显示；会话完成后的最终内容可恢复；本地持久化不应在每个 50 ms 刷新时同步阻塞 UI。 |
| 长会话公式 | 在含有普通文本与复杂公式的长会话中持续流式输出、向上滚动、加载更早消息并切回底部。 | 历史稳定消息不应随每次流式更新重新解析；公式内容和副本可见；默认 60 条窗口、显式加载早期历史和“跳到最新”保持有效。 |
| 减少动态 | 在 Windows 启用“显示动画效果”关闭或系统减少动态偏好后打开首页、消息、Inspector 和 Companion。 | 消息进入、Inspector、Companion 漂浮/阴影等非必要动画停止；所有按钮、焦点和关闭操作仍即时可用。 |
| 常规动效 | 在正常系统动效设置下打开 Inspector、接收新消息、聚焦输入框并切换主题。 | 动效仅提供短促空间/状态反馈，不阻塞滚动或输入；长会话与 SSE 期间不出现跳动、强制滚动或持续闪烁。 |
| 直连边界 | 在系统代理开/关的可用网络环境下发送普通 Provider 聊天。 | Provider 请求继续经过原生 HTTPS/SSE；性能和动效面板不额外发起 Provider、Gateway、文件扫描或后台服务请求。 |
