# AI Work OS 0.1.9 Windows 视觉回归清单

本清单验证 0.1.9 的 Apple 风格视觉打磨，而不改变普通聊天的 Tauri 原生 HTTPS/SSE 直连路径。安装器仍不得包含或启动显式 Gateway sidecar。

| 场景 | 操作 | 预期结果 |
|---|---|---|
| 明亮首页 | 以明亮主题打开应用并进入空闲聊天首页。 | 白灰材质、克制蓝色与轻量环境光形成层次；首屏保持紧凑，侧栏、聊天画布和输入框没有多余白框。 |
| 输入焦点 | 聚焦聊天输入框、输入文字并撤销焦点。 | 输入容器仅以轻微上移、阴影和蓝色描边反馈焦点；不跳动、不遮挡输入区。 |
| 消息时间线 | 发送连续对话并上下滚动。 | 用户气泡使用深浅蓝色渐变，助手气泡保持高对比浅灰材质；流式和滚动不被动画阻塞。 |
| Inspector | 依次打开项目记忆、上下文预算、检查点、GitHub 协作与本地用量账本。 | 每次只出现一个内容面、轻度背景模糊、固定标题栏和单独内容滚动；没有内部侧栏或自动 I/O。 |
| 减少动态 | 在 Windows 启用“减少动态效果”后重新打开应用。 | 新消息和 Inspector 不执行非必要进入动画；界面仍正常显示与操作。 |
| 深色主题与窄屏 | 切换深色主题并将窗口缩窄。 | 保留黑灰蓝层级、文本对比和关闭入口；Inspector 内容在自身区域滚动，不溢出到背景。 |
| 功能不回归 | 发送一轮已配置的第三方 Provider 聊天，查看记忆、检查点和 `/github` 面板。 | 直连 Provider、记忆批准、分支/导出、固定 `git diff --check` 预检及显式推送确认均保持原有行为。 |
| 云端来源 | 从 GitHub Windows runner 工件安装。 | 清单版本为 0.1.9，`canAutoStartGateway=false`、`bundlesExplicitGatewaySidecar=false`，SHA-256 与 SLSA provenance 对应发布提交。 |
