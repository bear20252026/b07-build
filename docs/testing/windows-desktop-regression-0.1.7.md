# AI Work OS 0.1.7 Windows 实机回归清单

本清单用于验证首页跨厂商模型切换、连接时间线和检索运行卡；所有 Provider 请求仍由桌面原生 HTTPS/SSE 直接发往用户选择的供应商，不经过 Gateway。

| 场景 | 操作 | 预期结果 |
|---|---|---|
| 跨厂商切换 | 在首页“厂商连接”切换两条已连接 Provider。 | 后续聊天的标题与任务选择变为新连接默认模型；地址和密钥不变，旧会话也不会被改写。 |
| 自由模型 | 在首页输入供应商文档规定的模型标识并点击“使用此模型”。 | 仅后续请求使用该模型；输入为空或含空格时不能提交。 |
| MiMo 图片 | 选择 `mimo-v2.5` 后发送 PNG/JPEG/WebP/GIF/BMP。 | 图片按 OpenAI-compatible 原生路径发送；`mimo-v2.5-pro` 的图片失败应提示显式切换视觉模型。 |
| 连接时间线 | 依次点击测试连接、流式测试并发送一轮真实聊天，再进入“已连接模型”。 | 每项显示独立追踪 ID、耗时、首 token（如有）、阶段和错误码；不显示密钥、正文、图片、代理地址或工作区路径。 |
| SearXNG 失败隔离 | 选择本地 SearXNG 并在服务失败时发送问题。 | 当前消息显示“失败已隔离”的搜索运行卡；原始问题仍继续发送给已选 Provider。 |
| 检索重试 | 点击失败运行卡的“准备以同一后端重试”。 | 原问题、后端和联网开关被预填到编辑器；不会自动发送、不会更改 Provider 或模型。 |
| 云端来源 | 安装器来自 GitHub Windows 工作流工件。 | 清单版本为 0.1.7，`bundlesExplicitGatewaySidecar=false`，来源证明匹配提交。 |
